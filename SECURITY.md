# Reporting a security issue

Do not include local device keys, account passwords, API secrets, signing material
or full device IDs in public issues, screenshots or logs. Use the repository's
private vulnerability reporting option if enabled. If unavailable, open an issue
requesting a private contact channel without disclosing the vulnerability or secrets.

The app stores configuration encrypted on the TV and uses the key only for local
device sessions. Signing files and private hardware captures are never part of
the public source export. No manufacturer app/cloud credentials are required to
build this project. Keep your own signing identity private and backed up offline.
